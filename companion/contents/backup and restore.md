# Backup and restore

Module này gồm các chức năng backup schedule và restore

## **1. Backup and Restore**

B1. Vào tab chức năng Backup&Restore (hình dưới)

B2. Tại màn hình chức năng backup&restore chọn:

-  Backup type (\*) chọn combo box:

    o  All tables

    o  EMS Configuration

    o  EPC Configuration

    o  Customize…

-  Trường hợp nếu chọn backup type là Customize, form nhập dữ liệu sẽ thêm bảng để chọn như dưới:

B3. Nhấn button Backup để lưu kết quả

---

## **2. Backup Schedule**

Vào tab chức năng backup schedule như hình dưới

**2.1. Create Backup Schedule**

B1. Vào tab chức năng Backup schedule

B2. Nhập dữ liệu tại vùng thông tin nhập dữ liệu [1], gồm:

-  Schedule name (\*)

-  Backup type

    o  All tables

    o  EMS Configuration

    o  EPC configuration

    o  Customize…

Trường hợp chọn backup type = customize, vùng thông tin nhập dữ liệu hiển thị thêm trường nhập tên bảng:

-  Chọn repeat: chu kỳ backup lặp lại theo:

    o  Day

    o  Week

    o  Month

-  Chọn thời gian backup

B4. Nhấn button create [2] để tạo mới một lịch backup dữ liệu, click button rest [3] để nhập lại từ đầu.

**2.2. Update Backup Schedule**

B1. Trên list danh sách bakup, chọn icon Edit dữ liệu, thông tin backup của bản ghi hiển thị trên vùng thông tin nhập dữ liệu.

B2. Thực hiện tay đổi thông tin về backup schedule

B2. Click button Update [4] để thực hiện thay đổi cấu hình backup
