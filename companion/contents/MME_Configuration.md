# MME Configuration

Đây là chức năng cho phép người dùng hiển thị, thêm mới, thay đổi hoặc xóa thông tin cấu hình cho MME.

**Sau khi đăng nhập, thực hiện vào mode MME Configuration như sau:**

*Welcome to vEPC SSH server   
[vEPC]#* *config-mode   
\*\*Configuration mode\*\*   
trangnth36 connected from 192.168.69.47 using console   
[vEPC] (Configuration)# mme-config-mode   
\*\*MME Configuration mode\*\*   
trangnth36 connected from 192.168.69.47 using console   
[vEPC] (MME Configuration)#*

**Sử dụng tab button để hiển thị các lệnh hệ thống hỗ trợ:**

*[vEPC] (MME Configuration)# <tab button>   
clear Negate or set default value for element   
commit Commit current set of changes   
exit Back to root item path or exit configure mode   
rollback Roll back database to last committed version   
save-config Save current configuration to a XML file   
set Create/modify configuration   
show Show information about the system*

*[vEPC] (MME Configuration)#*
