# Change Password

Đây là chức năng cho phép quản trị có thể đổi mật khẩu cho các user trong hệ thống.

Bước 1: Tại màn hình [User Management](UserManagement.md) , chọn thông tin user muốn thay đổi password

Bước 2: Click vào button Change Password

Bước 3: Tại cửa sổ thay đổi password, nhập thông tin new Password và confirm Password (giống nhau)

-  New Password(\*): Bắt buộc nhập, kiểu varchar (max 45 ký tự)

-  Confirm Password(\*): Bắt buộc nhập, kiểu varchar (max 45 ký tự)

Bước 4: Click button Change, thông tin password được thay đổi

**Ngoại lệ:**

-  Nhập confirm password và new password không giống nhau

-  Không nhập new password

-  Không nhập confirm password

-  Nhập new password, Confirm password quá độ dài ký tự cho phép
