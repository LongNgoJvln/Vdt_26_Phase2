# Software monitor

## **1. EPC Status**

Là chức năng hiển thị trạng thái của các node ứng dụng trong hệ thống.

Người dùng thực hiện vào chức năng EPC Status: hệ thống sẽ hiển thị toàn bộ các node đang giám sát

-  Màu xanh: Active

-  Màu vàng: Standby

-  Màu đỏ: Inactive

Xem trạng thái từng node

-  Click vào node

-  Hiển thị popup thông tin trạng thái của node

-  Các thông tin về node hiển thị gồm:

    o  Total Mem (MB)

    o  Process Mem (MB)

    o  ProcessUsed Mem (MB)

    o  ETS Mem (MB)

    o  Process Count

    o  CPU Usage (%)

## **2. Node monitor**

Là chức năng xem chi tiết theo biểu đồ trạng thái node ứng dụng

Người dùng thực hiện vào chức năng Node monitor: hệ thống sẽ hiển thị biểu đồ trạng thái toàn bộ các node đang giám sát

Bước 1. Nhập điều kiện view dữ liệu tại vùng thông tin nhập điều kiện đầu vào

Các thông tin cần nhập gồm:

-  Sub System

-  Node Name tương ứng với từng Sub System

-  Start Time

-  End Time

Bước 2. Click button View để xem kết quả

-  Có thể on/off từng đường biểu đồ bằng cách click chuột vào các label như ảnh dưới
