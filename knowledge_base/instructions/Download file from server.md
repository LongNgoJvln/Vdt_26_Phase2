# Download File From Server

Đây là chức năng cho phép người sử dụng download các file hoặc cả thư mục từ server về ví dụ như file trace (\*.pcap), các file config hệ thống, file xuất dữ liệu thuê bao, ...

Bước 1: Vào màn hình chức năng 'Download file from server' như hình sau:

Bước 2: Màn hình download file về như sau:

Bước 3: Nhập đường dẫn file từ server vào text Enter URL downloadd file. Có thể cho phép download 1 thư mục. (Hệ thống sẽ Auto nén thành file .zip)

Ví dụ: /u06/test.rar

Bước 4: Click button Download

Bước 5: Hệ thống thực hiện xác thực tính đúng đắn của file download, nếu file tồn tại trên server, thỏa mãn các điều kiện download thì hiển thị popup cho phép save file về máy cá nhân.

Bước 6: Người dùng chọn save file về máy và chọn 'OK' để thực hiện download hoặc chọn 'Cancel' để hủy thực hiện.
